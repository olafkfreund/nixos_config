# Intent: Spotifast native Spotify client on p620 and razer

## Problem

There is no Spotify client installed on the interactive hosts. Spotify is
only a commented-out line in `nixarchy-apps.nix`. Spotifast
(<https://spotifast.rocks>, `github:crmne/spotifast`) is a native Rust client
with library browsing, local playback and Spotify Connect. It is MIT licensed,
and upstream documents a Nix install as a flake input plus
`packages.<system>.default`.

## Proposed outcome

On p620 and razer, `spotifast` is on `PATH` and shows up in the app launcher,
which works because the package ships `spotifast.desktop`. It can be updated
with `nix flake update spotifast`.

## Affected users and systems

- Hosts: p620, razer. Not p510.
- Files: `flake.nix` and `flake.lock` (new input), `overlays/default.nix`
  (`pkgs.spotifast`), `Users/olafkfreund/profile.nix`. This is the same path
  herdr takes.
- User: olafkfreund.

## Constraints

- Explicit wiring only. p510 is never built or deployed as part of this task.
- Keep the binary cache intact: set `inputs.nixpkgs.follows` and
  `rust-overlay.follows` so no second nixpkgs is pulled in. Spotifast is not
  on any cache, so it is built from source. That means compiling Rust plus
  libprojectM with CMake, so razer builds it on p620.
- No secrets. Spotify login happens at runtime in the app.

## Open questions

Resolved at approval:

- Install only, no configuration. Sign-in happens in the app.
- The GNOME `spotify-controller` extension and `mpris-album-art` are left
  unchanged.
