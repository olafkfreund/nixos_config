# Intent: install the ArtCraft Crafting Apps on p620 and razer

## Problem

ArtCraft (storytold) publishes 12 native, pure-Rust creative apps: PhotoCraft,
VectorCraft, LightCraft, PdfCraft, EffectCraft, DesignCraft, FilmCraft,
GridCraft, SoundCraft, CADCraft, WordCraft and DeckCraft. They are open source
(MIT/Apache-2.0) and ship Linux release tarballs, but none of them is in
nixpkgs. Their prebuilt binaries cannot run on NixOS as they are, because they
expect `/lib64/ld-linux-x86-64.so.2` and load graphics libraries at runtime.
Their text tools also look for fonts only in `/usr/share/fonts`, which NixOS
does not have.

Two community flakes exist. One covers 7 of the 12 apps, and the other has
stale pins and no module. The user chose to package all 12 in our own flake,
`github:olafkfreund/nix-craftapps`, with NixOS and Home Manager modules and a
daily update workflow.

## Proposed outcome

- All 12 apps are installed on p620 and razer, with launcher entries and icons.
- Each app starts on the Omarchy (Hyprland) session.
- Each app's `<app>-cli` companion is on `PATH`.
- The text tools find the system fonts.
- New app releases arrive through `nix flake update nix-craftapps`, like any
  other input.

## Affected users and systems

- Hosts: p620 and razer. p510 does not get them.
- Files: `flake.nix` gains a new input. The two hosts' configurations, or the
  module they share, enable `programs.craftapps`.
- The fonts option adds a `/usr/share/fonts` symlink on both hosts and turns
  on `fonts.fontDir`.

## Constraints

- The input follows our `nixpkgs`, so the apps link against the same libraries
  as the rest of the system.
- No `readDir` and explicit imports only. Enabling the apps uses a flag, as
  the repo rules require.
- The apps are pre-1.0 and release daily. A broken release must not block a
  host build. The flake lock pins a known-good version, and bumps go through
  the normal `nhs` test-build path.
- Upstream release binaries come in by fixed hash. Building from source was
  ruled out: effectcraft has 26 git dependencies, and the large workspaces
  would compile on every bump.
- p510 is untouched, and razer is built on p620.

## Open questions

Resolved at approval:

1. System-wide, through the NixOS module, so `linkFonts` can provide
   `/usr/share/fonts`.
2. `nix-craftapps` stays public under `olafkfreund`.
