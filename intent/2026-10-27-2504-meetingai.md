# Intent: nixarchy-meetingai meeting copilot on p620

## Problem

The meeting copilot (github.com/olafkfreund/mixarchy-meetingai, branch
`refactor/omarchy-quickshell-rewrite`) is built and tested in its own repo,
but nothing installs it on a machine, so it has never run in a real meeting.
It needs four parts present together, which today exist on no host:

- the `nixarchy-meetingai` daemon as a user service (the AI providers,
  transcription, notes, the MCP server);
- a local whisper.cpp server with its model, for offline transcription;
- the Quickshell plugin `nixarchy.meetingai` (overlay and bar widget) in
  the Omarchy shell;
- keybindings to open the overlay and start/stop recording.

The project ships a Home Manager module that sets all four up, the same way
`nixarchy-meeting-mode` is installed here
(`hosts/common/nixos/omarchy-meeting-mode.nix`).

## Proposed outcome

- p620 runs the daemon and the local whisper server as user services that
  start with the session, and the Omarchy shell shows the meetingai bar
  widget and overlay.
- The flake pins the project by GitHub URL and branch, like the
  meeting-mode input, so the lock is reproducible.
- Ollama Cloud works without typing the key: the daemon gets it from the
  existing agenix secret `api-ollama` (`/run/agenix/api-ollama`, already
  decrypted for `users`).
- Nothing changes on razer or other hosts.

## Affected users and systems

- p620 only, user `olafkfreund`.
- `flake.nix` / `flake.lock` (new input), a new
  `hosts/common/nixos/omarchy-meetingai.nix`, and its import in
  `hosts/p620/nixos/nixarchy.nix`.
- The existing secret `secrets/api-ollama.age` is read, not changed.

## Constraints

- Declarative only: no `omarchy plugin add`, no imperative installs.
- The key never enters the Nix store. `/run/agenix/api-ollama` holds the
  bare token, not `KEY=value`, so the daemon must read it as a key file
  (a small option in the meetingai module), or a wrapper must export it.
- Branch work in this worktree, PR to `main`, deploy with the Justfile
  from `main`.
- The project's Whisper model download (large-v3-turbo, ~1.6 GB) happens
  once at build time.

## Open questions

2. **Bar placement:** enable the plugin's bar widget in the right section
   next to meeting-mode (proposed), or overlay and keybinds only?
3. **Keybindings:** use the module's defaults (proposed), or set them here?
