# Intent: an empty quiet.json doesn't silence agent summaries

## Problem

`agent-say` checks several "should I stay quiet?" gates before speaking. `gate_quiet`
reads `~/.local/state/omarchy/notifications/quiet.json` and treats anything it can't parse
as quiet (`pkgs/agent-say/agent_say.py`).

On razer that file is 0 bytes, dated Oct 22, so the gate is always closed:

```text
{'gate_switch': None, 'gate_dnd': None, 'gate_quiet': 'quiet', 'gate_mic': None}
```

Do Not Disturb reports `off` on the same machine. So razer never speaks a summary, in the
old voice or through Nixi, though the user turned it on there.

## Proposed outcome

- An empty `quiet.json` counts as "not asking for quiet", so razer speaks summaries.
- Real quiet still works: `dnd: true`, a snooze, or `silencedSince` keep him silent.
- A file with invalid content, or one that can't be read, still means quiet.
- After deploying, a real turn on razer is heard.

## Affected users and systems

`pkgs/agent-say` in nixos_config, on p620 and razer. p620's file has content, so nothing
changes there. p510 doesn't run `agent-say`.

## Constraints

- **Must:** keep failing closed on invalid JSON. A half-written file shouldn't make him talk
  during a call.
- **Must not:** change the other gates, or write to the file.

## Open questions

1. **A missing file:** today that also means quiet. Recommended: leave it as it is, because this
   issue is about the empty file, and nothing has shown a missing one.
2. **Fix the file on razer as well?** Recommended: no. It's Omarchy's file, and the code fix
   handles it.
