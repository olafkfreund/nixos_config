# Intent: an empty quiet.json doesn't silence agent summaries

## Problem

`agent-say` checks several "should I stay quiet?" gates before speaking. `gate_quiet`
reads `~/.local/state/omarchy/notifications/quiet.json` and treats anything it can't parse
as quiet (`pkgs/agent-say/agent_say.py`).

On razer that file is 0 bytes, dated Oct 22, so the gate is always closed:

```text
{'gate_switch': None, 'gate_dnd': None, 'gate_quiet': 'quiet', 'gate_mic': None}
```

Do Not Disturb reports `off` on the same machine. So razer never speaks a summary, in the
old voice or through Nixi, though the user turned it on there.

## Proposed outcome

- A zero-byte `quiet.json` that has stayed that way for a few seconds no longer blocks a summary
  that's otherwise allowed. The other gates still apply, as do turn length and Nixi's own state.
- A zero-byte file that's only just been written still means quiet, because it may be a file
  being rewritten.
- Real quiet still works: `dnd: true`, a snooze, or `silencedSince` keep him silent.
- Whitespace, invalid content, a missing file, and a file that can't be read all still mean quiet,
  as they do today.

## Affected users and systems

`pkgs/agent-say` in nixos_config, on p620 and razer. p620's file has content, so nothing
changes there. p510 doesn't run `agent-say`.

## Constraints

- **Must:** keep failing closed on invalid JSON. A half-written file shouldn't make him talk
  during a call. A zero-byte file is technically invalid too, so this is the one narrow exception,
  and only once it has been stable. Nothing here shows how Omarchy writes the file, so a truncate
  and rewrite has to stay safe.
- **Must not:** change the other gates, or write to the file.

## Open questions

1. **Code change, or just fix razer's file?** Recommended: the code change, because anyone whose file ends
   up empty silently loses every summary, and nothing tells them why. The alternative is writing
   `{"dnd":false}` to razer's file once: no code, but the trap stays.
2. **A missing file:** today that means quiet, and a test asserts it. Recommended: leave it as it is,
   since nothing has shown a missing one, though it does mean a fresh machine could hit the same silence.
