# Intent: delete dead modules and fix the module templates

## Problem

About 25 `.nix` files are imported by nothing: orphan `default.nix` wrappers whose leaves hosts import directly
(`modules/{nix,system,system-utils,storage,secrets,windows,fonts,scripts,funny}/default.nix`), an empty
`modules/networking/default.nix`, `modules/nix-index/` (the flake uses the upstream module), a commented-out
`modules/services/flaresolverr/` and `modules/email/auth/`, unused Home Manager modules (`home/shell/lazygit`,
`home/shell/ssh`, `home/development/shell.nix`, `home/desktop/thunderbird`, `home/desktop/terminals/alacritty`,
`home/desktop/terminals/wezterm/colors.nix`), and host leftovers (`hosts/p620/nixos/syncthing.nix`,
`hosts/p510/microvm.nix` with a `builtins.readDir` on a missing directory, `hosts/{p620,razer}/nixos/override/`).
`flake.nix` passes `sharedVariables` and `hardwareProfiles` in `specialArgs`, which nothing reads.
`checks/default.nix:90-100` fails the build unless every `modules/<dir>/` has a `default.nix`, which is why the
wrappers exist. `modules/TEMPLATE.nix` teaches `options.modules.*` and `modules/SYSTEMD_SERVICE_TEMPLATE.nix` a
static service user, both against AGENTS.md.

## Proposed outcome

The dead files are gone, the check no longer demands wrappers, and both templates show the house pattern. Every
host builds the exact same system as before.

## Affected users and systems

Repository only; no host changes.

## Constraints

Behaviour-preserving: `scripts/config-snapshot.sh` reports p620, razer and p510 `IDENTICAL` against `main`. A file is
deleted only if the hosts still evaluate and stay identical without it.
