# Intent: rewrite p510's Home Manager file without the mkForce wall

## Problem

`Users/olafkfreund/p510_home.nix` imports both `home/profiles/server-admin` and `home/profiles/developer`, which set
the same feature flags to opposite values, and then needs 24 `lib.mkForce` lines to make it evaluate. Its comments
call p510 a headless server, but p510 has been a desktop since 2026-08-31, and modules such as
`home/media/music.nix` and `home/desktop/default.nix` were never headless anyway. A reader cannot tell what p510
really gets; the two profiles are used by nothing else.

## Proposed outcome

`p510_home.nix` states p510's actual choices plainly, imports what it needs directly, and needs at most one
`mkForce` (delta, against `private.nix`). p510's Home Manager result is the same: same packages, same generated
files, same user services, same programs.

## Affected users and systems

p510 (Home Manager for `olafkfreund`); `home/profiles/{developer,server-admin}` become unused and are deleted.

## Constraints

- No package, file, program or user service is added or lost on p510.
- p510 is evaluated and its configuration built on p620 only (owner OK for this roadmap); never deployed here.

## Open questions

None.
