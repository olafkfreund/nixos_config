# Intent: fleet constants, allowBroken and honest aggregator names

## Problem

- p620's tailnet address `100.69.100.115` is typed in five places (`hosts/common/nixos/nixi-fleet.nix:14`,
  `hosts/p510/configuration.nix:759,774`, `hosts/p620/configuration.nix:97,480`, `hosts/razer/configuration.nix:504`)
  and its LAN address `192.168.1.65` in two (`hosts/p620/configuration.nix:774`, `hosts/p510/configuration.nix:350`).
  When an address changes, one copy is missed.
- `nixpkgs.config.allowBroken = true` is set on all three hosts (`hosts/*/configuration.nix`), silently accepting
  packages nixpkgs marks broken.
- Aggregator files do not import what their names say: `modules/development.nix` imports `ai/` and `helpers`, while
  every host imports `modules/development/default.nix` itself; `modules/performance.nix` imports `storage/`.
  `modules/overlays/default.nix` is a one-overlay module beside the top-level `overlays/`.

## Proposed outcome

Fleet addresses live in one file; `allowBroken` is off unless a host really needs it; aggregators import what their
names say and hosts stop importing `development/` by hand. Every host builds exactly the same system.

## Affected users and systems

`hosts/`, `modules/*.nix` aggregators; p620, razer, p510.

## Constraints

Behaviour-preserving: `scripts/config-snapshot.sh` `IDENTICAL` on all three hosts. Any item that changes a `.drv`
is dropped from this task and reported. Out of scope: removing packages declared in both system and Home Manager
(it changes the Home Manager closure for no runtime gain; the duplicates are harmless).
