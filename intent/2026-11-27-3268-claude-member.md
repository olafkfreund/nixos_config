# Intent: Claude Code as a herdr-team member

## Problem

`herdr-team` can start Codex (`review`, `implement`) and agy
(`agy-implement`) as team members, but not Claude Code. A session led from
Codex or agy therefore cannot hand a step to a Claude coder or ask a Claude
reviewer through the same team tab, and the shared Team policy (#3264) only
works one way round.

## Proposed outcome

Two more roles, `claude-review` and `claude-implement`, start an interactive
Claude Code in the team tab on the role map's reviewer and worker models
(#3263), take prompts through `herdr-team ask` and `converse`, and report
each finished turn the same way the Codex and agy members do. The
implementer runs under the same coder guard as the other implementers; the
reviewer is read-only.

## Affected users and systems

herdr-team on p620 and razer; Claude Code's managed hook files.

## Constraints

- Subscription login only: no `ANTHROPIC_API_KEY`, no `--bare`.
- Members never stage, commit, deploy or restart (the coder guard).
- Works in both herdr backends, like the existing roles.

## Open questions

None.
