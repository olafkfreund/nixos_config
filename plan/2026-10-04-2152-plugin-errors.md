# Plan: clear the remaining Omarchy plugin and shell errors

## Decisions (from the approved spec)

- **Crash watcher:** `ConditionUser=!@system` on the nixarchy user unit, so
  it never starts for the SDDM greeter (uid 175).
- **Omarchy `shell.qml:1424`:** the panel `Loader` error handler calls a
  nonexistent `errorString()`. Carry a nixarchy patch that uses
  `sourceComponent.errorString()` or the source URL; file an upstream issue.
- **webcam `Panel.qml:206`:** guard the deferred `applyState` call. Local
  branch in the clone, upstream PR.
- **omarecorder `Service.qml:172`:** `printErrors: false` on the `state.json`
  `FileView`. Fresh git clone replaces the hand copy; local branch, upstream
  PR.
- **winvm:** install through Nix from olafkfreund/nixarchy-winvm; re-check.
- **hyprforge:** update; re-check.
- **ai-mirror, unknown plugin ids:** re-check only.
- **`nixarchy.pkg`:** remove from bar-folder's `widgets`.
- **Gemini icon:** restore. **`Claude desktop.desktop`:** delete.
- **Upstream posts:** each text goes to the user before posting.

## Steps

### A. nixarchy (olafkfreund/nixarchy)

nixarchy has its own intent/spec/plan workflow (its `AGENTS.md`). Both
changes go in there as one task, with this plan's two decisions as the
proposed design.

1. `modules/nixos.nix:1889-1909` (`omarchy-crash-watch`): add
   `ConditionUser = "!@system";` to `unitConfig`. Extend the existing
   crash-watch assertion in `tests/options.nix:4069`, or add one, so the
   generated unit carries the condition.

   Verify by `nix build .#checks.x86_64-linux.options`, or the relevant check.
2. `pkgs/omarchy/NNNN-panel-loader-errorstring.patch` (new, numbered by
   nixarchy's convention, `-p1` against `share/omarchy`). It replaces
   `var detail = errorString && errorString() ? errorString() : ""` and the
   following `sourceComponent` line in `shell/shell.qml` with
   `var detail = sourceComponent ? sourceComponent.errorString() : String(source)`.
   Wire it in `pkgs/omarchy/default.nix` next to the `1155-panel-loaders-kept.patch`
   line (432-436), using the same `patch --forward --fuzz=0` form.

   Verify by building the omarchy package and grepping the output tree for
   the new line; run `checks.session`.

   Traps: `--fuzz=0` fails loudly if upstream moves the line, which is
   intended.
3. Merge in nixarchy, then here run `nix flake update nixarchy` and commit
   as `chore(flake): bump nixarchy for crash-watch and panel errors (#2152)`.
   Note: a nixarchy bump also brings any other nixarchy changes since the
   last bump. Read the lock diff and summarise it in the PR.
