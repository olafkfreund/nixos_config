# Plan: install the ArtCraft Crafting Apps on p620 and razer

Approved decisions, carried over from the spec:

- **Source.** The 12 apps come from `github:olafkfreund/nix-craftapps`, our own
  public flake, built from upstream release tarballs by fixed hash. The input
  follows our `nixpkgs`.
- **Install route.** It is system-wide, through the flake's NixOS module, with
  `linkFonts = true` (the default), which provides `/usr/share/fonts`.
- **Per-app choice** (deviation, requested by the user during
  implementation). `features.craftapps.apps.<name>` is a bool for each of the
  12 apps, default `true`. It maps to the flake's `programs.craftapps.apps.<name>.enable`.
  Each host lists all 12, so including or excluding one is a one-word edit.
- **Feature flag.** Enabling goes through `features.craftapps.enable` in a new
  `modules/desktop/craftapps.nix`, set on p620 and razer only.
- **p510** imports the module through `hosts/templates/desktop.nix` →
  `modules/desktop.nix` → `modules/desktop/default.nix`, but never sets the
  flag. Its toplevel drvPath must not change.

## Steps

0. **Prerequisite, in the nix-craftapps repo.** The flake is pushed to `main`,
   and `nix flake check` passes there: every app builds and the module
   evaluates. This plan does not start until that holds.

1. **`flake.nix` (near line 301, after the `herdr` input):** add the input.

   ```nix
   nix-craftapps = {
     url = "github:olafkfreund/nix-craftapps";
     inputs.nixpkgs.follows = "nixpkgs";
   };
   ```

   Then run `nix flake lock --update-input nix-craftapps`. Verify with
   `nix flake metadata | grep craftapps`.
   Traps: `flake.lock` changes only for this input. Check with
   `git diff --stat flake.lock`; no other node should move.

2. **New file `modules/desktop/craftapps.nix`:** it imports
   `inputs.nix-craftapps.nixosModules.default` unconditionally. It defines
   `features.craftapps.enable`, plus `features.craftapps.apps.<name>`: one
   bool option per app, default `true`, with the names read from
   `${inputs.nix-craftapps}/apps.json`. Under `mkIf cfg.enable` it sets
   `programs.craftapps.enable = true` and
   `programs.craftapps.apps = mapAttrs (_: enable: { inherit enable; }) cfg.apps`.
   Verify with `just check-syntax`.
   Traps: the import must be unconditional (imports cannot depend on config).
   `inputs` comes from `specialArgs`. No `mkIf cond true`.

3. **`modules/desktop/default.nix`:** add `./craftapps.nix` to `imports`,
   after `./sunshine.nix`. Verify with
   `nix eval .#nixosConfigurations.p510.config.features.craftapps.enable`,
   which should print `false`.

4. **`hosts/p620/configuration.nix:495` and
   `hosts/razer/configuration.nix:340`:** next to `features.themeOwner.enable`,
   add a `features.craftapps` block with `enable = true;` and an `apps` set
   listing all 12 apps as `true`.
   Verify that
   `nix eval .#nixosConfigurations.p620.config.programs.craftapps.packages --apply 'map (p: p.pname)'`
   lists all 12. Also verify that an `extendModules` override with
   `features.craftapps.apps.soundcraft = mkForce false` lists 11.

These are small edits to five files, so the session implements them
itself rather than handing them to a coder; the model-split rule lets an
approved plan of this size stay in the session.

## Tests

1. `just check-syntax` and `nix flake check --no-build` pass.
2. The p620 and razer toplevels build:
   `nix build --no-link .#nixosConfigurations.{p620,razer}.config.system.build.toplevel`.
3. p510 is unchanged:
   `nix eval --raw .#nixosConfigurations.p510.config.system.build.toplevel.drvPath`
   is identical on `origin/main` and on the branch. If it differs, `nix-diff`
   must show no change. Evaluating a new input whose packages are not
   referenced should leave the drvPath unchanged.
4. Nothing else claims `/usr/share` on p620 or razer:
   `nix eval .#nixosConfigurations.p620.config.systemd.tmpfiles.rules --json | jq -r '.[]' | grep /usr/share`
   shows only the craftapps lines.
5. After deploy, run on each host:
   - `ls /run/current-system/sw/share/applications/ai.storyteller.*.desktop | wc -l`
     gives `12`;
   - this loop prints 12 lines ending `ok`:

     ```bash
     for a in photocraft vectorcraft lightcraft pdfcraft effectcraft designcraft \
              filmcraft gridcraft soundcraft cadcraft wordcraft deckcraft; do
       $a-cli --help >/dev/null && echo "$a ok"
     done
     ```

   - `readlink /usr/share/fonts` resolves, and `ls /usr/share/fonts/` is not
     empty;
   - `timeout 8 photocraft`, `timeout 8 effectcraft` and `timeout 8 deckcraft`
     on the Hyprland session each exit `124`, meaning they stayed up, with no
     missing-library panic. On razer this runs only when a desktop session is
     logged in; otherwise it is done at the next login.

## Rollback

Revert the PR, then run `just p620` and `just deploy-via-p620 razer`, or roll
back to the previous generation with `sudo nixos-rebuild switch --rollback`.
The `/usr/share/fonts` symlink is managed by tmpfiles, so a configuration
without the rule stops recreating it; remove it with
`sudo rm /usr/share/fonts`.
