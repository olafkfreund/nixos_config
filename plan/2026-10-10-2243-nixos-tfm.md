# Plan: package tfm-tui as the nixos-tfm flake and install it on p620 and razer

## Approved decisions (carried over from the spec)

- **Upstream:** `clarkarch/tfm-tui` v1.0.0 (MIT). Release assets are
  `tfm-{x86_64,aarch64}-linux.gz`, each with a `.gz.sha256` sidecar holding a
  hex sha256.
- **Build from the release binary.** gunzip it to `$out/libexec/tfm` and run
  `patchelf --set-interpreter "$(cat $NIX_CC/nix-support/dynamic-linker)"`.
  - Do **not** use `autoPatchelfHook`.
  - Set `dontStrip = true`, because the app is a payload in the ELF `.bun`
    section.
  - The only `NEEDED` libraries are glibc's.
- **Wrapper** (`makeWrapper $out/libexec/tfm $out/bin/tfm`):
  - `--set-default TFM_FFMPEG <ffmpeg>/bin/ffmpeg` when `withFFmpeg`.
  - `--suffix PATH : <makeBinPath extraPackages>`.
- **Package arguments:** `withFFmpeg ? true`, `ffmpeg ? ffmpeg-headless`,
  `extraPackages ? [ unzip zip p7zip ]`.
- **`meta`:** MIT, `platforms = [ x86_64-linux aarch64-linux ]`,
  `mainProgram = "tfm"`, `sourceProvenance = [ binaryNativeCode ]`.
- **Shared options under `programs.tfm`** (NixOS and Home Manager):
  - `enable`
  - `package` (default: this flake's `tfm`)
  - `ffmpeg.enable` (default true) and `ffmpeg.package` (default
    `ffmpeg-headless`)
  - `extraPackages` (default `[ unzip zip p7zip ]`)
  - `finalPackage`: read-only,
    `package.override { withFFmpeg; ffmpeg; extraPackages; }`
- **The NixOS module** adds `finalPackage` to `environment.systemPackages`.
- **Home Manager:**
  - It adds `finalPackage` to `home.packages`.
  - `settings` is a TOML attrset, default `{ }`; `forceSettings` is a bool,
    default `false`.
  - When `settings != { }`, `home.activation.tfmConfig` runs after
    `writeBoundary`. It writes the generated TOML to
    `${XDG_CONFIG_HOME:-$HOME/.config}/tfm/config.toml` if the file is missing
    or `forceSettings` is set: it removes a symlink there first, then runs
    `install -Dm644` through `run`.
  - Otherwise it leaves the file alone.
- **Updates:** `scripts/update.sh` takes the latest non-prerelease tag. If it
  is new, it fetches both `.sha256` sidecars, converts them to SRI and rewrites
  `sources.json`. `update.yml` runs it daily, then `nix flake check`, then opens
  a PR and dispatches `ci.yml`. CI runs `nix flake check` on `ubuntu-latest`
  and `ubuntu-24.04-arm`.
- **Checks:** `package` (`tfm --version` matches, and the wrapper carries
  `TFM_FFMPEG`) and `module` (a nixosSystem with ffmpeg off has the package and
  no `TFM_FFMPEG`). There is no Home Manager input.
- **This repo:**
  - Input `nixos-tfm` following `nixpkgs`.
  - `modules/desktop/tfm.nix` (`features.tfm.{enable,settings}`) uses
    `home-manager.sharedModules`.
  - p620 is enabled first; razer only after p620 is verified and the user
    agrees.
  - Docs page with nav in **both** mkdocs files.

## Steps

### Part A: the `nixos-tfm` repo (local clone at `~/Source/GitHub/nixos-tfm`)

1. **Create the repo.** Run `gh repo create olafkfreund/nixos-tfm --public
   --description "tfm (clarkarch/tfm-tui), the mouse-first terminal file
   manager, for NixOS and Home Manager" --license mit --clone` into
   `~/Source/GitHub/`.
   → Verify by `gh repo view olafkfreund/nixos-tfm --json visibility` returning
   `PUBLIC`.
   Traps: this publishes externally. Nothing personal goes in the repo: no
   hostnames, IPs or `/home/olafkfreund` paths.

2. **`sources.json`, `package.nix`, `flake.nix`** (packages, overlay,
   formatter) as decided above. Get the hashes with
   `curl -fsSL …/v1.0.0/tfm-<arch>-linux.gz.sha256 | cut -d' ' -f1 | xargs
   nix hash convert --hash-algo sha256 --to sri`.
   → Verify by
   `nix build .#tfm && ./result/bin/tfm --version` printing `tfm 1.0.0`, and
   `grep TFM_FFMPEG result/bin/tfm`.
   Traps:
   - `git add` new files before any `nix` command; a flake ignores untracked
     files.
   - `fetchurl` of a `.gz` must not auto-unpack, so use `fetchurl`, not
     `fetchzip`.

3. **`modules/common.nix`, `modules/nixos.nix`, `modules/home-manager.nix`**
   as decided above. `common.nix` takes the flake's package set the way
   nix-craftapps does (`import ./modules/nixos.nix self`), so the default
   `package` resolves for the module's own `pkgs.system`.
   → Verify by `nix flake check -L` (step 4 adds the checks).
   Traps:
   - The activation script uses `$DRY_RUN_CMD`/`run` and `lib.hm.dag.entryAfter
     [ "writeBoundary" ]`.
   - `lib.hm` exists only in Home Manager, so keep it out of `common.nix`.

4. **`checks` in `flake.nix`** (`package` and `module`).
   → Verify by `nix flake check -L` passing on p620.
   Traps: the module check needs `boot.loader.grub.enable = false`, a tmpfs
   `/` and `system.stateVersion`; copy this from nix-craftapps.

5. **`scripts/update.sh`**, `.github/workflows/{ci,update}.yml`.
   → Verify by running `scripts/update.sh` locally. It must exit 0 with
   `sources.json` unchanged, since 1.0.0 is the latest.
   Traps: the workflows mirror nix-craftapps' `update.yml`. PRs opened with
   `GITHUB_TOKEN` do not trigger CI, so finish with `gh workflow run ci.yml
   --ref <branch>`.

6. **`README.md`**:
   - What tfm is, with a link to upstream.
   - Getting started:
     - `nix run github:olafkfreund/nixos-tfm`
     - flake input
     - NixOS module example
     - Home Manager module example, including `settings`
   - Options table.
   - Config seeding and `forceSettings`.
   - ffmpeg, helpers and optional tools.
   - Updates.
   - How it is built: release binary plus interpreter patch.
   - Licence.

   Also `.gitignore` (`result*`).
   → Verify by `markdownlint README.md`, if it is available.

7. **Commit and push to `main`.** Conventional Commits; this is a new repo with
   no branch protection. Then wait for CI.
   → Verify by `gh run watch` showing both arches green.
   Traps: write the commit body with `-F - <<'MSG'`, not backticks in `-m`.

## Tests

- `nixos-tfm`: `nix flake check -L` passes on x86_64 locally and on both
  arches in CI. `nix run github:olafkfreund/nixos-tfm -- --version` prints
  `tfm 1.0.0`.
- This repo: `just check-syntax` and `just test-host p620` succeed. PR CI
  `check-configurations` passes for p620, razer and p510.
- Runtime, after step 13: the checks listed in step 13, and the same on razer
  after step 14.

## Rollback

- p620/razer: set `features.tfm.enable = false` (or `git revert` the merge)
  and redeploy, or `sudo nixos-rebuild switch --rollback`. A seeded
  `~/.config/tfm/config.toml` stays behind and is harmless; delete it by hand
  if wanted.
- This repo: revert the PR; the flake input goes with it.
- `nixos-tfm`: archive or delete the repo with `gh repo delete`, but only on
  the user's explicit request.
