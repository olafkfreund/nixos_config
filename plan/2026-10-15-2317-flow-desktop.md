# Plan: install Flow Desktop via the nixos-FlowTube flake

Approved decisions, self-contained:

- Source: `github:olafkfreund/nixos-FlowTube` as a flake input named
  `flowtube`, with `inputs.nixpkgs.follows = "nixpkgs"`. Its
  `homeManagerModules.default` provides `programs.flow-desktop.enable`.
- Shape: copy `modules/desktop/tfm.nix`. A NixOS module defines
  `features.flow-desktop.enable`, and under `mkIf` it appends the HM module
  plus `{ programs.flow-desktop.enable = true; }` to
  `home-manager.sharedModules`.
- Hosts: p620 and razer set the flag. p510 does not, and its toplevel
  drvPath must not change.
- razer is never built on razer; p620 builds it.
- Already verified: the package builds against our nixpkgs pin `7fd4004`
  with the flake's hashes, and the result is in p620's store.

All work happens in the worktree `~/.config/nixos-2317`, on branch
`feat/2317-flow-desktop`. Never touch `~/.config/nixos`.

## Steps

0. Baseline, before any edit: record p510's toplevel drvPath.

   ```bash
   nix eval --raw .#nixosConfigurations.p510.config.system.build.toplevel.drvPath > /tmp/p510-before
   ```

   Traps: none.

1. `flake.nix`, after line 293 (the closing `};` of `nixos-tfm`): add

   ```nix

    # Flow Desktop, a privacy-respecting YouTube client (Issue #2317): our own
    # flake, built from source. Enabled by features.flow-desktop.
    flowtube = {
      url = "github:olafkfreund/nixos-FlowTube";
      inputs.nixpkgs.follows = "nixpkgs";
    };
   ```

   Then run `nix flake lock`, which adds only the new input.
   → Verify: `git diff --stat flake.lock` touches only `flowtube` nodes, and
   `jq -r '.nodes.nixpkgs.locked.rev' flake.lock` is still `7fd4004d…`.
   Traps: never use `nix flake update`, which would move every input and the
   nixpkgs pin.

2. New file `modules/desktop/flow-desktop.nix`, with exactly the module in
   the spec, under Design step 2. `git add` it immediately, because a flake
   cannot see untracked files.
   → Verify: `nix-instantiate --parse modules/desktop/flow-desktop.nix`.
   Traps: explicit imports only, no `mkIf cond true`. This is a user app, so
   the service-hardening rule does not apply.

3. `modules/desktop/default.nix`, line 10: after `./tfm.nix`, add
   `./flow-desktop.nix`.
   → Verify: `just check-syntax`.
   Traps: none.

4. `hosts/p620/configuration.nix`, after line 516, and
   `hosts/razer/configuration.nix`, after line 361 (the closing `};` of
   `features.tfm`), add:

   ```nix
   features.flow-desktop.enable = true;
   ```

   → Verify with the eval tests below.
   Traps: never edit `hosts/p510/`.

5. Commit as `feat(desktop): install Flow Desktop via nixos-FlowTube (#2317)`.
   Write the message to a file and pass it with `git commit -F`, with no
   backticks. Push, and open a PR that links the intent, spec and plan.

6. After the PR merges and `~/.config/nixos` is back on `main`, deploy:
   - Read `#agents` on the agent bus, then post "deploying p620 then razer
     via p620, Flow Desktop (#2317), ~20 min".
   - Run `just quick-deploy p620`, then `just deploy-via-p620 razer`.
   - Then run the runtime checks below on p620.

   Traps: the deploy recipes refuse branches other than `main`
   (`_require-main`). p510 is not deployed. Read the "units failed" line,
   because exit 4 can be cosmetic on razer (syncthing) and p510.

## Tests

| Check | Command | Expect |
| ----- | ------- | ------ |
| Enabled on hosts | `nix eval .#nixosConfigurations.p620.config.home-manager.users.olafkfreund.programs.flow-desktop.enable`, and the same for razer | `true` |
| p510 untouched | Diff `/tmp/p510-before` against a fresh p510 drvPath eval | identical |
| p620 builds | `just test-host p620` | succeeds; the Flow store path is reused, no Rust compile |
| razer builds (on p620) | `just test-host razer` | succeeds |
| Runtime (p620) | Launch Flow from the launcher and play a video | window renders, video plays |
| Scheme | `xdg-mime query default x-scheme-handler/flow` | `Flow.desktop` |
| Decoders | `grep gstreamer_decoder_probe ~/.local/share/io.github.aedev.flow.desktop/logs/*` | `avdec_h264="present"` |
| No stray entry | `ls ~/.local/share/applications/ \| grep -i flow` | nothing |

## Rollback

- Before merge: close the PR and delete the branch and worktree.
- After deploy: revert the merge commit on `main` and redeploy. For an
  immediate undo on one host, use `sudo nixos-rebuild switch --rollback`.
  The app's data in `~/.local/share/io.github.aedev.flow.desktop` stays until
  it is removed by hand.
