# Plan: run the agy guard probe automatically, and document the coder guard

## Approved decisions (from intent and spec)

- When `agy-implement` meets an agy version not recorded in
  `${XDG_CACHE_HOME:-$HOME/.cache}/agy-implement/probed`, it probes
  automatically. It holds a `flock` on `probe.lock`, re-checks after taking
  the lock, sends the probe's stdout to stderr, then continues if `probed`
  now matches, or refuses if it doesn't. There is no timer and no
  activation hook.
- To avoid a Nix cycle, `agy-implement` calls
  `AGY_IMPLEMENT="$0" ${agyGuardProbe}/bin/agy-guard-probe`, and the probe
  calls `"${AGY_IMPLEMENT:-agy-implement}"` instead of
  `${agyImplement}/bin/agy-implement`.
- Fail closed: an empty `agy --version`, a failed probe or a timeout all
  refuse. `AGY_IMPLEMENT_PROBING=1` still skips the gate for the probe's own
  inner run. Guard checks don't change.
- Docs: a new `docs/tooling/agy-coder-guard.md`, linked under Tooling in
  `mkdocs.yml` and `mkdocs-full.yml`. The handoff skill and
  `/update-antigravity` drop the manual probe step.
