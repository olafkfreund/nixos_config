# Plan: omapop selection-bar plugin on p620 and razer

## Approved decisions (from the spec)

- Package omapop (`jondkinney/omapop`, MIT) as `pkgs/omapop`, modelled on
  `pkgs/omadroid/default.nix`. It is `stdenvNoCC`, has no build, and pins
  rev `7d6b1aa0e5cb14f7d8bf24f9e78ffcad5deb00f7` (manifest version 0.4.11).
  It is **not** a flake input, so `nhs` never bumps it unreviewed.
- Every core `/usr/bin/...` path becomes a store path through
  `substituteInPlace --replace-fail`, so an upstream change fails the build.
  Optional PopClip-port tools (deno, node, browsers, zeal, espeak-ng, lp,
  xdg-terminal-exec) stay on `/usr/bin` for envfs.
- Child `PATH` becomes
  `/run/current-system/sw/bin:/etc/profiles/per-user/olafkfreund/bin:/usr/bin:/bin`.
- Python is `python3.withPackages [ pyyaml pygobject3 ]`.
  `GI_TYPELIB_PATH` is set inside `bin/omapop-context.py`, because children
  get a cleared environment.
- Vendor upstream PR #10 (the Qt 6.12 `Color` fix) as
  `pkgs/omapop/qt612-color.patch`. Drop it once an upstream bump contains it.
- `directoryRefresh` is off by default in three places: `Service.qml:170`
  and two in `manifest.json` (via `jq`).
- Decisions: the accessibility probe stays on, there is no deno, and the
  upgrade signal is a `# Bump against:` comment plus a check-updates line.
  There is no `just` recipe.
- The host module sets
  `programs.nixarchy.plugins."io.github.jondkinney.omapop".src`, with
  `hyprland = config.programs.hyprland.package`. Never
  `config.programs.nixarchy.package`, which causes infinite recursion. It is
  imported on p620 and razer only.

## Rollback

Remove the two import lines from `hosts/{p620,razer}/nixos/nixarchy.nix` and
redeploy. Or roll back a generation: `sudo nixos-rebuild switch --rollback`
on the host. Runtime state in `~/.config/omapop` and the omapop entry in
`~/.config/omarchy/shell.json` is harmless if left behind. Disable first
with `omarchy plugin disable io.github.jondkinney.omapop` if the shell is
still running the plugin. The package files can stay or be removed by
reverting the PR.
