# Plan: hello-lock lock screen on p620 and razer

## Decisions carried from the approved spec

- **Package `pkgs/hello-lock`:**
  - `stdenvNoCC.mkDerivation`, version `0.5.3`.
  - Source: `fetchFromGitHub denonmaryland/hello-lock`, rev
    `b52d2c2f34cb44e85dd950148ec41696f300c594`, hash
    `sha256-d0B+rrkcgWb9neFGU6SiUQ8/yrMLCf/t7ONIHlJYdxQ=`.
  - Installed to `$out/share/hello-lock/plugin`, without `docs/`, `tests/`
    and `preview.png`.
  - `patchShebangs` on `bin/`, with `python3` and `bash` as inputs. No
    other patching, no build step.
- **Host wiring:** `hosts/common/nixos/omarchy-hello-lock.nix` sets
  `programs.nixarchy.plugins.hello-lock.src` and
  `local.omarchy.enableOnce = [ "hello-lock" ]`, following
  `omarchy-omateams.nix`. It is imported by p620 and razer only.
- **Lock route:** Omarchy routes the lock to the enabled plugin with
  `clonedFrom: "omarchy.lock"`. Disabling hello-lock gives the stock lock
  screen back. Nothing stock is touched.
- **Weather:** upstream default (on), and it can be turned off in
  hello-lock's settings.
- **First-run setup:** runs once per host. `~/.config/hello-lock/` stays
  user state.
- **Docs:** new page `docs/applications/hello-lock.md`, listed in both
  `mkdocs.yml` and `mkdocs-full.yml`.
- **Recovery:** `omarchy plugin disable hello-lock && omarchy restart shell`,
  from a TTY or SSH.
- **Rejected:**
  - `omarchy plugin add` (unpinned);
  - a bare `fetchgit` as `src` (env shebangs, 8.5 MB of docs);
  - a flake input;
  - a Nix-managed `config.json`;
  - disabling the stock lock from Nix.

## Rollback

- **Fast, per host:**
  `omarchy plugin disable hello-lock && omarchy restart shell` brings back
  the stock lock screen.
- **Full:** revert the PR and redeploy. The plugin symlink goes away.
  `~/.config/hello-lock/` and the enable-once stamp
  (`~/.local/state/nixarchy-local/enabled-once/hello-lock`) remain and
  can be deleted by hand.

## Deviations during implementation

  `#!/usr/bin/env -S python3 -I` shebangs to

  the store, so the `substituteInPlace` fallback was not needed.
- **Step 1, extra scripts:** `fixupPhase` also patched
  `sounds/generate.sh` and `typing/harness/run.sh`. This is harmless.
