# Plan: an empty quiet.json doesn't silence agent summaries

## Approved decisions

- A zero-byte `quiet.json` that has stayed so for more than 5 seconds no longer closes `gate_quiet`.
- A just-written zero-byte file, whitespace, invalid content, a missing file and an unreadable file all
  stay quiet.
- The file is read first, so an unreadable one can't count as clear.
- `dnd`, a snooze and `silencedSince` work as before. The other gates don't change. Nothing writes the file.
- A missing file stays quiet, as approved.
- Known effect, approved in the spec: razer's turn text starts reaching its configured `claude -p` backend, which
  this bug had been holding back. Say so in the PR.
