# Plan: the Herdr desktop app and herdr-core (hc) on p620 and razer

Approved decisions (intent + spec):

- Two new `pkgs/` derivations from the `releases.herdr.dev` tarballs,
  pinned by sha256: `herdr-core` 0.1.20 (static, plus an `hc` symlink) and
  `herdr-app` 0.1.15 (autoPatchelf + wrapper, modelled on `pkgs/okena`).
- **Self-update off:** never install `herdr-app.svg` next to the binary,
  because the updater (`update::find_root`) only runs when it is there.
  Backstop: `HERDR_RELEASES_URL=file://<local manifests>`, which always
  reports "current".
- Wrapper: `HERDR_CORE_DIRS=<herdr-core>/bin`, `HERDR_TELEMETRY=0`,
  `DO_NOT_TRACK=1`, plus the runtime libraries and `PATH` entries. We never
  write the app's `settings.json`.
- `hc` and `herdr-app` skills with YAML frontmatter, next to the TUI's
  `herdr` skill, under `programs.herdrSkill.enable`.
- Installed in the developer profile, so on p620 and razer only.
- razer gets linger for the owner only; p620 already has it.
- Adoption is gated: Verification 1-9 must pass on both hosts, or a removal
  PR takes the packages back out.

## Steps

1. **New `pkgs/herdr-core/default.nix`** (spec §1).
   - Shape: `let version = "0.1.20"; in stdenv.mkDerivation (finalAttrs: { pname = "herdr-core"; inherit version; … })`.
     The `let` binding is what later `let` values can use, and inside the
     derivation `finalAttrs.version` and `finalAttrs.finalPackage` are in
     scope.
   - `src = fetchurl { url = "https://releases.herdr.dev/core/${version}/herdr-core-linux-x86_64.tar.gz"; sha256 = "ac6b86890c451a37584620aaa438b71bc0d0bd430a2e7c1d7e095f052c414e74"; }`.
   - `sourceRoot = ".";` (the tarball has `herdr-core`, `LICENSE` and
     `THIRD-PARTY-NOTICES` at the top level).
   - `installPhase`:
     - `install -Dm755 herdr-core $out/bin/herdr-core`
     - `ln -s herdr-core $out/bin/hc`
     - docs to `$out/share/doc/herdr-core/`
   - `dontStrip = true` and no patchelf (static-pie).
   - `passthru.skill`: a directory output, like `herdrSkill` in
     `home/development/herdr.nix:23-26`:
     `runCommand "herdr-core-skill" { } '' mkdir -p $out; { cat ${frontmatter}; HOME=$TMPDIR ${finalAttrs.finalPackage}/bin/herdr-core --skill; } > $out/SKILL.md ''`,
     where `frontmatter` is a `writeText` holding exactly:

     ```text
     ---
     name: hc
     description: "Run and steer long-lived terminals and coding agents with herdr-core (hc): hc run, send, wait, read, attach. Use when the user mentions hc or herdr-core. Not the Herdr TUI (that is the herdr skill)."
     ---
     ```

   - `meta`: license `asl20`, `platforms = [ "x86_64-linux" ]`,
     `mainProgram = "hc"`.
   - Comment: what it is, and the bump checklist: version + hash from
     `https://releases.herdr.dev/core/latest.json`, then Verification 2-7
     and 9 on p620. At a core bump, check that a running old server keeps
     its terminals across `hc server restart`.

   → verify: `nix-instantiate --parse pkgs/herdr-core/default.nix`.
   Traps: explicit imports only; no `with pkgs;` at the top.

2. **New `pkgs/herdr-app/default.nix`** (spec §2). Copy the shape of
   `pkgs/okena/default.nix`.
   - Shape: `let version = "0.1.15"; releases = …; in stdenv.mkDerivation (finalAttrs: { pname = "herdr-app"; inherit version; … })`.
     `releases` uses the `let` `version`, not `finalAttrs`.
   - `src = fetchurl { url = "https://releases.herdr.dev/app/${version}/herdr-app-linux-x86_64.tar.gz"; sha256 = "f99e1e04be82c0e10b2f69ee7403ca34386f480d92511df5865af4703e7655dd"; }`;
     `sourceRoot = "herdr-app";`.
   - `nativeBuildInputs = [ autoPatchelfHook makeWrapper copyDesktopItems ]`;
     `buildInputs = [ libxkbcommon libxcb stdenv.cc.cc.lib ]`.
   - `installPhase`:
     - `install -Dm755 herdr-app $out/bin/herdr-app`
     - `install -Dm444 herdr-app.svg $out/share/icons/hicolor/scalable/apps/herdr-app.svg`
     - the docs
     - **Never** put `herdr-app.svg` in `$out/bin`. Write a comment saying
       why: `update::find_root` needs it beside the canonicalised exe, and
       leaving it out disables the in-app updater.
   - `desktopItems = [ (makeDesktopItem { name = "herdr-app"; desktopName = "Herdr"; exec = "herdr-app"; icon = "herdr-app"; categories = [ "Development" "TerminalEmulator" ]; comment = "Native app for running coding agents"; }) ]`.
   - `releases` (in the `let`):

     ```nix
     releases = linkFarm "herdr-releases" [
       { name = "app/latest.json"; path = writeText "app.json" (builtins.toJSON { inherit version; }); }
       { name = "core/latest.json"; path = writeText "core.json" (builtins.toJSON { version = herdr-core.version; generation = 1; }); }
     ];
     ```

   - `postFixup`: `wrapProgram $out/bin/herdr-app` with
     - `--prefix LD_LIBRARY_PATH : ${lib.makeLibraryPath [ vulkan-loader libglvnd wayland libxkbcommon ]}`
     - `--prefix PATH : ${lib.makeBinPath [ curl pipewire herdr-core ]}`
     - `--set HERDR_CORE_DIRS ${herdr-core}/bin`
     - `--set HERDR_RELEASES_URL file://${releases}` (no trailing slash)
     - `--set HERDR_TELEMETRY 0`
     - `--set DO_NOT_TRACK 1`
   - `passthru.skill`: the same directory-output `runCommand` as in step 1,
     from `${finalAttrs.finalPackage}/bin/herdr-app --skill`, with
     `name: herdr-app` and
     `description: "Drive the person's Herdr desktop window (spaces, tabs, panes) with herdr-app. Use only when the user asks to arrange or show something in the Herdr app; terminals and agents themselves are the hc skill."`.
     It runs with `HOME=$TMPDIR`, and through the unwrapped binary if the
     wrapped one needs a display. If `--skill` needs neither, use the
     wrapped one.
   - `meta`: as in step 1, with `mainProgram = "herdr-app"`. The comment
     holds the bump checklist (the app manifest, and Verification 6
     re-run).

   → verify:
   - `nix-instantiate --parse pkgs/herdr-app/default.nix`.
   - After step 3: `nix build .#nixosConfigurations.p620.pkgs.customPkgs.herdr-app`.
     Then `ls result/bin` shows no `.svg`, and
     `grep HERDR result/bin/herdr-app` shows the five variables.

   Traps:
   - `copyDesktopItems` needs `runHook postInstall` in `installPhase`.
   - `libglvnd` provides `libEGL.so.1`.
   - Don't add `xdg-utils`; the session provides it.

## Rollback

- Fast: switch the host to its previous generation (announced, with
  `AGENT_BUS_ANNOUNCED=1`).
- Permanent: a revert PR from a worktree branch, merged, then deploy both
  hosts.
- Left behind in `~/.config/herdr-app` and `~/.config/herdr-core`: the
  app's settings and the core's state. They are harmless and can be removed
  by hand.
- A running `hc` server keeps running until `hc server stop`.
