# Plan: enable llm-index on p620 for Claude Code, Codex and agy

## Summary of approved decisions

- **Flake input.** Add `nixarchy-llm-index`, pinned by revision in the URL
  to the merge commit of nixarchy-llm-index#8. It follows `nixpkgs` and
  `home-manager`. `nix flake lock` adds only this input.
- **Host module.** New `hosts/common/nixos/llm-index.nix`, imported only by
  p620. It configures Home Manager `services.llm-index`:
  - root `source` = `/mnt/code/Source-home`, public;
  - root `docs` = `~/Documents`, private;
  - `limits.memoryMaxMb = 2048`;
  - the package added to `home.packages`;
  - `~/.claude/rules/llm-index.md` holding the module's
    `agentInstructions`;
  - a converging activation entry, `llmIndexMcp`, for Claude Code, Codex
    and agy, public tier only.
- **Codex and agy instructions.** `home/development/agent-rules.nix` adds
  the instructions only when `services.llm-index.enable`. Other hosts'
  generated `AGENTS.md` files keep the same store path.
- **Deploy.** Bus announcement, then `just p620` from the shared checkout
  after the merge. Retire the trial afterwards, with its own announcement.

2. New file `hosts/common/nixos/llm-index.nix`, with exactly this content
   (`nixfmt` may reflow it):

   ```nix
   # nixarchy-llm-index: local document and code index served to agents over MCP
   # (#2882). ~/Source is public, ~/Documents private; only the public server is
   # registered, in Claude Code, Codex and agy, by the converging activation below.
   { inputs, ... }:
   {
     home-manager.users.olafkfreund =
       { config, lib, pkgs, ... }:
       let
         cfg = config.services.llm-index;
         jq = "${pkgs.jq}/bin/jq";
         want = cfg.mcpServers.public;
         wantJson = builtins.toJSON { inherit (want) command args; };
       in
       {
         imports = [ inputs.nixarchy-llm-index.homeManagerModules.default ];

         services.llm-index = {
           enable = true;
           roots = {
             source = {
               path = "/mnt/code/Source-home"; # real path; ~/Source is a symlink
               tier = "public";
             };
             docs.path = "${config.home.homeDirectory}/Documents"; # private by default
           };
           limits.memoryMaxMb = 2048; # the 1 GB default throttled at 768 MB in the trial
         };

         home.packages = [ cfg.package ];
         home.file.".claude/rules/llm-index.md".text = cfg.agentInstructions;

         # Converge each client's `llm-index` entry on the current store path; write only
         # on a difference. Never `exit`: activation entries are one script.
         home.activation.llmIndexMcp = lib.hm.dag.entryAfter [ "writeBoundary" ] ''
           _llm_want=$(echo ${lib.escapeShellArg wantJson} | ${jq} -cS .)
           for _llm_c in claude codex agy; do
             _llm_b=""
             for _llm_d in "${config.home.profileDirectory}/bin" /run/current-system/sw/bin; do
               if [ -x "$_llm_d/$_llm_c" ]; then _llm_b="$_llm_d/$_llm_c"; break; fi
             done
             [ -n "$_llm_b" ] || continue
             case "$_llm_c" in
               claude) _llm_have=$(${jq} -cS '.mcpServers["llm-index"] // empty | {command, args}' "$HOME/.claude.json" 2>/dev/null || true) ;;
               codex) _llm_have=$("$_llm_b" mcp get llm-index --json 2>/dev/null | ${jq} -cS '.transport | {command, args}' 2>/dev/null || true) ;;
               agy) _llm_have=$(${jq} -cS '.mcpServers["llm-index"] // empty | {command, args}' "$HOME/.gemini/config/mcp_config.json" 2>/dev/null || true) ;;
             esac
             if [ "$_llm_have" != "$_llm_want" ]; then
               _llm_s=""; [ "$_llm_c" = claude ] && _llm_s="-s user"
               $DRY_RUN_CMD "$_llm_b" mcp remove $_llm_s llm-index >/dev/null 2>&1 || true
               if $DRY_RUN_CMD "$_llm_b" mcp add $_llm_s llm-index -- ${lib.escapeShellArgs ([ want.command ] ++ want.args)} >/dev/null 2>&1; then
                 echo "llm-index: registered in $_llm_c"
               else
                 echo "llm-index: could not register in $_llm_c"
               fi
             fi
           done
         '';
       };
   }
   ```

   → verify with `nix-instantiate --parse hosts/common/nixos/llm-index.nix`.

   Traps:
   - Keep `''` escapes. `${…}` inside the string is Nix interpolation on
     purpose; shell variables use `$_llm_*` with no braces.
   - Do not add `exit`.
   - **Deviation from the spec wording, recorded here:** a missing entry
     and an unreadable one are treated the same. Both lead to
     remove-then-add, and a failed add prints the warning. Adding is safe
     in both cases, so no error is hidden.
