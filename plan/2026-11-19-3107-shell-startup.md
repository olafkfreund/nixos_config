## Steps

1. **Probe** (`$SP/probe/startup-probe`, `$SP/probe/startup-probe.service`;
   coder: fable). Bash script, `set -euo pipefail`, deps by absolute store
   path or `nix shell` (socat, jq, hyprland's hyprctl, procps, coreutils).
   Reads `$XDG_RUNTIME_DIR/hypr/$HYPRLAND_INSTANCE_SIGNATURE/.socket2.sock`
   (waits up to 10 s for it); writes `<epoch.ns> <record>` lines to
   `~/.local/state/startup-probe/<epoch>.log`: `probe-start`, each
   `openlayer`/`closelayer` line, after each a compact snapshot
   (`hyprctl -j layers` reduced to `[monitor, level, namespace]` for
   `omarchy-background` and `omarchy-bar`), and `intro-start` / `intro-exit`
   from a 50 ms `pgrep -f omarchy-theme-bg-boot-intro` poll. Exits 90 s after
   start. Unit: `Type=simple`, `PartOf=graphical-session.target`,
   `After=graphical-session-pre.target`, `WantedBy=graphical-session.target`.
   A report script `$SP/probe/startup-report <log>` prints, per login, the
   gate-proxy table (all times relative to session start, in ms):

   | Gate (`BackgroundIntro.qml`) | Proxy |
   |---|---|
   | session start | journal `sddm-helper`: "Starting Wayland user session" |
   | shell up | journal omarchy-shell: "Launching config", "Configuration Loaded" |
   | `desktopReady` (bar part) | first `openlayer>>omarchy-bar` |
   | `backgroundReady` | journal owed: "shell background enabled" |
   | `startupSettled` | `intro-exit` |
   | reveal (end of 420 ms fade) | first snapshot with no level-3 `omarchy-background` on any monitor |

   plus the count of "performing full rescan" in the new shell's `.qslog`
   (decode with `quickshell log <file> --no-color --log-times -r
   '*.debug=true'`) within 60 s of "Launching config". It labels every
   number a proxy and prints the limits: the bar's `openlayer` does not show
   when the registry scan or a plugin reload settled; owed's line shows when
   owed was ready, not when the shell saw `backgroundReady`. A sample is
   void if `probe-start` is later than "Launching config" or no level-3
   cover was ever seen.
   → verify: `bash -n`, shellcheck clean; dry run against the live session
   (`HYPRLAND_INSTANCE_SIGNATURE` from the running Hyprland, 5 s) produces a
   well-formed log; report script runs on it.
   Traps: never pick the newest hypr directory (Linger keeps old ones);
   nothing goes into the repo.

8. **shell.json** (lead), on p620 then razer (razer over ssh, in its
   session environment). In `~/.config/omarchy`:

   ```bash
   F='del(.bar.hiddenRevealByRegion, .bar.revealIcons)
      | .bar.layout |= map_values(map(if type == "object" and (.hidden | type) == "string"
                                      then del(.hidden) else . end))'
   cp -p shell.json shell.json.bak-3107
   h=$(sha256sum < shell.json)
   jq "$F" shell.json.bak-3107 > .shell.json.new
   jq -e '.version == 1' .shell.json.new
   [ "$(sha256sum < shell.json)" = "$h" ] && mv .shell.json.new shell.json  # else start again
   omarchy-shell shell reloadConfig
   omarchy-shell shell listShellConfig | jq -S . > /tmp/live.json
   jq -S "$F" shell.json.bak-3107 > /tmp/want.json
   diff /tmp/want.json /tmp/live.json   # empty
   jq '[.bar.hiddenRevealByRegion, .bar.revealIcons,
        ([.. | objects | select((.hidden | type) == "string")] | length)]' shell.json  # [null,null,0]
   ```

   The tray's array-valued `hidden` (`Tray.qml:23`) is kept by the filter.
   If `listShellConfig` adds defaults the file lacks, the `diff` is not
   empty for that reason alone: then compare `jq -S . shell.json` with
   `/tmp/want.json` instead, and check only the three keys in the live
   config.
   A write between the hash and the `mv` is still lost (accepted; the backup
   is the recovery).
   → verify: as stated; re-check the file after the next login.
   Traps: never write the file while the hash differs; keep the backup.
