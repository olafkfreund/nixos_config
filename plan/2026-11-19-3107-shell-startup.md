## Steps

1. **Probe** (`$SP/probe/startup-probe`, `$SP/probe/startup-probe.service`;
   coder: fable). Bash script, `set -euo pipefail`, deps by absolute store
   path or `nix shell` (socat, jq, hyprland's hyprctl, procps, coreutils).
   Reads `$XDG_RUNTIME_DIR/hypr/$HYPRLAND_INSTANCE_SIGNATURE/.socket2.sock`
   (waits up to 10 s for it); writes `<epoch.ns> <record>` lines to
   `~/.local/state/startup-probe/<epoch>.log`: `probe-start`, each
   `openlayer`/`closelayer` line, after each a compact snapshot
   (`hyprctl -j layers` reduced to `[monitor, level, namespace]` for
   `omarchy-background` and `omarchy-bar`), and `intro-start` / `intro-exit`
   from a 50 ms `pgrep -f omarchy-theme-bg-boot-intro` poll. Exits 90 s after
   start. Unit: `Type=simple`, `PartOf=graphical-session.target`,
   `After=graphical-session-pre.target`, `WantedBy=graphical-session.target`.
   A report script `$SP/probe/startup-report <log>` joins the log with
   journal lines (sddm-helper session start, omarchy-shell "Launching
   config" / "Configuration Loaded", owed "shell background enabled") and
   the qslog rescan count, and prints the gate-proxy table and validity.
   → verify: `bash -n`, shellcheck clean; dry run against the live session
   (`HYPRLAND_INSTANCE_SIGNATURE` from the running Hyprland, 5 s) produces a
   well-formed log; report script runs on it.
   Traps: never pick the newest hypr directory (Linger keeps old ones);
   nothing goes into the repo.

2. **Baseline** (lead + owner). Copy the unit to
   `~/.config/systemd/user/`, `systemctl --user daemon-reload`,
   `systemctl --user enable startup-probe.service`. Owner logs out and in
   twice. Run the report on both logs and keep them in `$SP/probe/baseline/`.
   → verify: both samples valid (probe started before "Launching config",
   level-3 cover seen and closed).
   Traps: re-login is disruptive to the desktop only; post on the agent bus
   first.

3. **keepLoaded PRs** (coder: fable). For each of
   olafkfreund/nixarchy-devenv (`manifest.json` `keepLoaded`, ~line 64),
   nixarchy-distrobox (~76), nixarchy-microvm (~72), nixarchy-winvm
   (`manifest.json`): clone to `$SP/repos/<repo>`, branch
   `perf/no-keeploaded`, remove the `keepLoaded` line (fix the trailing
   comma), and update comments that say the view stays loaded (grep
   `keepLoaded\|stays loaded\|clean slate` in `*.qml`, `README*`, `docs/`).
   Run the repo's own tests if present. The lead commits, pushes and opens
   each PR with a body that says: why (shell startup, #3107 in
   olafkfreund/nixos_config), what stays safe (state in the singleton or
   detached), the small losses (spec), and that keyboard opens use
   `shell toggle`. → verify: `jq -e 'has("keepLoaded")|not' manifest.json`;
   tests pass; PR CI green.
   Traps: no backticks in `git commit -m` (use `-F`); bus guard matches
   prose, so bodies go in files.

4. **hyprforge PR** (coder: codex, via `handoff`). In a clone of
   olafkfreund/nixarchy-hyprsettngs at `$SP/repos/nixarchy-hyprsettngs`,
   apply `$SP/fix/hyprforge.diff` to `Service.qml` (lines ~63-89: install
   script compares first, `removeScript` and `Component.onDestruction`
   removed), and update `Service.qml:9-10` and `README.md:277-278`.
   → verify: the repo's `test/embedded-sh.js` extraction, `sh -n`,
   shellcheck; inotifywait over an unchanged, a hyprchroma-themed, a
   missing, a foreign and a symlinked entry (0 events for unchanged and
   themed; foreign and symlink untouched). Lead commits, pushes, opens PR.
   Traps: `\\n` inside the JS string must reach sh as `\n`; keep the atomic
   `mv -fT` in the same directory.

5. **Pin in this repo** (lead). After the PRs from steps 3-4 merge, in
   `flake.nix` under `nixarchy = { ... }` next to the herdr and gltui

   - the same for `nixarchy-distrobox` and `nixarchy-microvm`;
   - `inputs.nixarchy-hyprsettngs.url = "github:olafkfreund/nixarchy-hyprsettngs/<rev>";`
     plus `inputs.nixarchy-hyprsettngs.flake = false;`
   Then `nix flake lock` and `nix flake update nixarchy-winvm`.
   → verify: `jq` on `flake.lock` shows each at its rev; no new
   `nixpkgs_N` node (compare node names before/after); `just check-syntax`;
   `just test-host p620`; `just test-host razer`.
   Traps: pins live in `flake.nix`, not only the lock (#3080); confirm each

   Traps: p510 untouched; razer over Tailscale if off the LAN; nvidia or
