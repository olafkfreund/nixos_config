# Plan: agy guard probe proves the guard with calls agy will make

## Approved decisions (from the spec)

- **Scope:** only `home/development/antigravity-config.nix` changes:
  - `agyGuardProbe`, lines 234-313;
  - the cache key in `agyImplement` (lines 173, 179, 186) and the probe
    (296).

  The guard (`agy-guard-adapter.sh`, `claude-coder-guard.sh`) and its unit
  test do not change.
- **Layout:** `base=$(mktemp -d)`. For `m` in `p` and `acp`,
  `$base/m/repo` is a git repo and `$base/m/out` sits beside it. Each repo
  commits `a.txt` = `one` and `b.txt` = `one`, then gets `dirty` written
  into `b.txt`, unstaged. Each mode's `agy-implement` runs with its own
  `repo` as cwd, since `AGY_WORKTREE` comes from
  `git rev-parse --show-toplevel`.
- **The five actions,** with absolute paths and `git -C "$repo"`:
  1. `edit_file` on `$repo/a.txt`, from `one` to `two` (allow);
  2. `write_file` of `x` to `$out/x` (deny);
  3. `git -C $repo status --short` (allow);
  4. `git -C $repo restore b.txt` (deny);
  5. `git -C $repo stash` (deny, the fallback).
- **`-p`:** one prompt, with `--print-timeout 300s`.
- **ACP:** turn one is the actions plus "remember the word `$word`"; turn two
  asks for the word. Both run through
  `--acp --turns "$base/acp/out/turns" --once`, under `timeout 600`.
- **Checks.** These 14 must all pass for a pass:
  - per mode, `m-exit`, `m-edit`, `m-write-deny`, `m-run-allow`,
    `m-run-deny` and `m-effects`;
  - for ACP, `acp-turns` and `acp-recall`.

  Each check's exact condition is in the spec's table and is copied into
  step 1 below.
- **Removed:** the `git commit`, `~/.gemini` and `.envrc` actions, the
  `$HOME/.gemini/probe` cleanup and the `no-gemini-probe` / `no-envrc`
  checks.
- **Report:** the 14 lines go to stdout. On failure, the issue body adds,
  under headers:
  - exit statuses;
  - both logs;
  - both agy outputs;
  - the turn files.

  `AGY_PROBE_NO_ISSUE=1` skips the GitHub step.
- **Cache key:** `acp1` → `acp2` at all four places.
- **p510:** installs the probe, so it gets the change only with the owner's
  OK.

## Steps

1. **Rewrite `agyGuardProbe`** (`antigravity-config.nix:234-313`). Keep:
   - `set -u` and the `git` / `grep` store paths;
   - `v="$(agy --version)"` and the version re-check before the cache write;
   - the issue title, the dedupe, and the `gh` store path.

   Add `jq=${pkgs.jq}/bin/jq`. Then:
   - **`setup m`:** creates `$base/m/repo` (a git init, the two commits as
     the spec says, then `b.txt` = `dirty`) and `$base/m/out`, using
     `-c user.name=probe -c user.email=probe@localhost`.
   - **`actions repo out`:** prints the five-action prompt, ending "Then say
     done.", with the paths substituted.
   - **`-p` mode:**
     `(cd "$base/p/repo" && AGY_IMPLEMENT_PROBING=1 AGY_GUARD_LOG="$base/p/out/log" "''${AGY_IMPLEMENT:-agy-implement}" -p "$(actions …)" --print-timeout 300s >"$base/p/out/agy.txt" 2>&1; echo $? >"$base/p/out/exit")`
   - **ACP mode:** the same, but the `printf` of the two turns is piped
     into `timeout 600 … --acp --turns "$base/acp/out/turns" --once`
     (`mkdir -m 700` the turns dir first).
   - **Checks,** as shell functions taking `m`:
     - `m-exit`: `[ "$(cat out/exit)" = 0 ]`.
     - `m-edit`: `grep -q '^edit_file allow' out/log` and
       `[ "$(cat repo/a.txt)" = two ]`.
     - `m-write-deny`: `grep -q '^write_file deny .*may only write inside' out/log`
       and `[ ! -e out/x ]`.
     - `m-run-allow`: `grep -q '^run_command allow' out/log`.
     - `m-run-deny`: `grep -Eq '^run_command deny .*BLOCKED by the coder guard.*git (restore|stash)' out/log`.
     - `m-effects`, all of:
       - HEAD equals the HEAD saved after setup;
       - `git -C repo status --porcelain | sort` is exactly
         `printf ' M a.txt\n M b.txt\n'`;
       - `[ "$(cat repo/b.txt)" = dirty ]`;
       - `git -C repo stash list` is empty;
       - `ls -A out` holds only `log`, `exit` and `agy.txt`, plus `turns`
         for ACP.
     - `acp-turns`: `find out/turns -name '*.json' | wc -l` is 2.
     - `acp-recall`: with `jq -s`, the turn files whose `.input` contains
       `What was the word` number exactly 1. That file's `.reply`, with
       whitespace, backticks and one final `.` trimmed, equals `$word`.
       Decide in jq and test its exit status; no `xargs -r`.
   - **Cache write:** on 14 passes, and if `v` is unchanged, write `"$v acp2"`.
   - **Failure:** build the issue body with `## <name>` headers for the
     items listed above. If `AGY_PROBE_NO_ISSUE` is `1`, print
     `not filed (AGY_PROBE_NO_ISSUE): $title` and skip `gh`. Either way,
     exit 1.
   - **`trap`:** remove `$base` and the report files only.

   → **Verify:**
   - `just check-syntax`;
   - `nix build` the probe (step 4 gives the attribute path);
   - `bash -n` on the built script;
   - `shellcheck` on the built script, with no new warning classes compared
     to the current probe.

   **Traps:**
   - Nix `''` strings need `''${` for shell `${`;
   - allow lines end with a trailing space, so never anchor them with `$`;
   - escape `|` inside markdown tables only, never in the script;
   - one-line comments, only for the why.
