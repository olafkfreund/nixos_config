# Plan: login cover lifts through the normal path on p620

## Approved decisions (from the spec)

- The startup reaper's `registry.rescan()` (`services/PluginRegistry.qml:702-706`)
  becomes `registry.rescan(true)`, a **check**:
  - it sets its own `checking` flag, not `scanning`, so `desktopReady`
    (`BackgroundIntro.qml:23`, reads `scanning` only) is not held;
  - `rescan()`'s own guard (`:755`) and the shell's three guards
    `rescanPlugins()` (`shell.qml:1588`), `reloadPlugins()` (`:1596`) and
    `finishPluginReload()` (`:1609`) test `scanning || checking`. Requests
    that arrive during a check go pending, as during a scan today.
- When the check's raw stdout equals the stored output of the last
  **successful full** scan (`hasScanOutput` true, exit code 0), the registry:
  - clears `checking`;
  - sets `lastScanSkipped = true`;
  - emits `scanFinished()` only.

  There is no `pluginsChanged()`, and `installedPlugins` and
  `registryRevision` stay untouched. Otherwise it sets `scanning = true`
  around the normal parse and publishes exactly as today. A full parse sets
  `lastScanSkipped = false`, and each successful full scan stores its output.
- `onScanFinished`'s plain branch (`shell.qml:1635-1638`) skips
  `_syncServices`, `syncPanelEntries` and `syncPluginWidgets` only when
  `pluginRegistry.lastScanSkipped && !shell.pluginReloading`. The reload and
  pending branches stay as they are.
- Existing gaps stay as they are: the check is dropped if the first scan is
  still running, and the watcher starts without waiting for its watches.
- **Owner decisions (spec approval, 2026-11-23):**
  - the check does not hold `desktopReady`;
  - the fix is carried in nixarchy, and an upstream PR to `basecamp/omarchy`
    is the owner's separate call.
- **Phase 1, p620 only, in this repo:**
  - two patches applied in `postInstall` of an `overrideAttrs` on
    `programs.nixarchy.package`, in this order:
    1. `hosts/p620/nixos/omarchy-3181-reaper-check.patch` (the fix);
    2. `hosts/p620/nixos/omarchy-startup-timing.patch` (timing, gated by
       `OMARCHY_STARTUP_TIMING=1`);
  - both with `patch -d $out/share/omarchy -p1 --forward --fuzz=0`;
  - `environment.sessionVariables.OMARCHY_STARTUP_TIMING = "1"`.
- **Phase 2:** once the login log shows `check-skip unchanged`, no sync after
  it, and nothing missing, the fix becomes a carried nixarchy patch under a new
  nixarchy issue. This repo drops both local patches and bumps the pin.
  `fade-start normal` is not a gate. If the timer still wins, the intent's
  outcome stays open and a follow-up issue is opened.

1. **Fix patch** (Phase 1). Copy `$S/shell/services/PluginRegistry.qml` and
   `$S/shell/shell.qml` into a scratch tree `work/a`, and copy that to
   `work/b`. In `work/b`:
   - `PluginRegistry.qml`:
     - add `property bool checking: false`, `property bool hasScanOutput: false`,
       `property string lastScanOutput: ""`, `property bool lastScanSkipped: false`,
       and a private `property bool _checkRun: false` next to `scanning`;
     - `rescan(onlyIfChanged)`: return if `scanning || checking`. When
       `onlyIfChanged && hasScanOutput`, set `checking = true` and
       `_checkRun = true`. Otherwise set `scanning = true` and
       `_checkRun = false`. Start the same `scanProcess`;
     - `scanProcess.onExited(exitCode)`: if `_checkRun` and
       `output === lastScanOutput`, then set `lastScanSkipped = true`,
       `checking = false` and emit `scanFinished()`. Otherwise:
       - if it was a check, set `checking = false` and `scanning = true`;
       - set `lastScanSkipped = false`;
       - parse as today; `parseScanOutput` still clears `scanning` and emits
         both signals;
       - on `exitCode === 0`, store `lastScanOutput` and set
         `hasScanOutput = true`;
     - `watcherReaper.onExited`: `registry.rescan(true)`.
   - `shell.qml`: the guards at `:1588`, `:1596` and `:1609` read
     `(shell.pluginRegistry.scanning || shell.pluginRegistry.checking)`. In
     `onScanFinished`, wrap the three syncs in
     `if (!(shell.pluginRegistry.lastScanSkipped && !shell.pluginReloading)) { … }`.
   - Cut `hosts/p620/nixos/omarchy-3181-reaper-check.patch` with
     `diff -ru` (relabelled to `a/shell/…` and `b/shell/…`), with a short
     header that names #3181 and says it is temporary until Phase 2.

   → **Verify:**
   - `patch --dry-run -d <copy of $S> -p1 --forward --fuzz=0` applies;
   - the offscreen harness from #3165 shows only the same error classes as the

   - `onExited` takes `exitCode` (`function(exitCode)`); keep that signature;
   - `parseScanOutput` sets `scanning = false` itself (`:674`), so do not
