# Plan: Provider-neutral team policy, 2 reviews per task

Decisions (approved spec): the team policy moves out of the Claude-only
"Model split" section into "## Team policy", rendered with a role/model
table from `modules/programs/agent-team.nix` into the managed CLAUDE.md and
both AGENTS.md files; Claude-only mechanics go into "## Claude Code
mechanics (Claude Code only)", which the AGENTS.md renderer cuts (with
everything after it, as today). Default reviews with `agent-team: on`: one
plan review (Codex; agy when Codex leads) and one diff review by a provider
other than the implementer's. Reviews run on the reviewer model: Codex
`-p review` (new profile), agy `--model gemini-4-neon-medium`.
