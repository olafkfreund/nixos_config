# Plan: Claude Code as a herdr-team member

Decisions (approved spec): roles `claude-review` (reviewer.claude model and
effort, `--permission-mode plan`) and `claude-implement` (worker.claude,
`--permission-mode bypassPermissions`, plus the coder guard as a `PreToolUse`
`Bash` hook), kind `claude`, in both backends. Turns are reported by a new
sink run as the member's `UserPromptSubmit` and `Stop` hooks, passed with
`--settings <file>`, writing the same turn files the Codex and agy members
write, with `source: "claude"`. herdr-team accepts Claude Code's
workspace-trust question once during start-up. No API key, no `--bare`.

## Steps

1. Sink `home/development/claude-sink.py` (+ `claude-sink-test.py`), packaged
   in `home/development/agent-run.nix` as `herdr-team-claude-sink`
   (`writeShellApplication` that `exec`s python3 on it; checkPhase runs the
   test against the packaged script).
   - Usage: `herdr-team-claude-sink prompt <turns-dir>` and
     `herdr-team-claude-sink stop <turns-dir>`; the hook JSON is on stdin.
     The turns dir must be a real directory (not a symlink), owned by the
     caller, mode 0700; otherwise do nothing. Read at most 1 MiB of stdin.
     Always exit 0, print nothing.
   - `prompt`: take `.prompt` (string); write it to `<turns>/.claude-input`
     via an exclusive temp file and `os.replace`.
   - `stop`: if `.stop_hook_active` is true, do nothing. Reply = the string
     `.last_assistant_message` if present and non-empty; otherwise read
     `.transcript_path` (a regular file, at most 16 MiB) as JSONL, find the
     last entry of `type == "user"` whose message content is the saved
     input, and join the `text` blocks of the `assistant` entries after it
     with blank lines. Input = contents of `.claude-input` (missing → do
     nothing). Write `<turns>/<uuid4>.json` =
     `{"turn_id", "input", "reply", "source": "claude"}` through an
     exclusive `.<id>.tmp` then a no-clobber rename (`os.link` + unlink, as
     `mv -n` does), refusing an existing or symlinked target; then remove
     `.claude-input`.
   - Tests (fixture transcripts in a temp dir): text-only reply; reply
     spread over two assistant entries with a tool call between; string vs
     list `content` on the user entry; `last_assistant_message` preferred;
     `stop_hook_active` ignored; missing input file; non-0700 or symlinked
     turns dir; symlinked target; non-JSON stdin; oversize transcript.
   → verify: `python3 home/development/claude-sink-test.py home/development/claude-sink.py`
   prints `ALL PASSED`; the package builds.

2. Coder guard at a stable path, `modules/programs/claude-code-managed.nix`:
   next to `environment.etc."claude-code/.claude/agents/coder.md"`, add
   `environment.etc."claude-code/hooks/coder-guard".source = coderGuardScript;`.
   → verify: the p620 toplevel builds.

3. herdr-team (`home/development/herdr-team.sh`, `agent-run.nix`,
   `herdr-team-test.sh`).
   - `agent-run.nix`: the text prefix gains
     `claude_sink=<herdr-team-claude-sink bin>`, `claude_review_model`,
     `claude_review_effort`, `claude_worker_model`, `claude_worker_effort`
     from the role map; `herdr-team-claude-sink` joins `home.packages`.
   - Header usage and both `up_*` role checks: add `claude-review` and
     `claude-implement`. `wrapper=claude` for both; `kind=claude`;
     `max` as for `review` / `implement` respectively.
   - In both argv blocks, for the claude roles: write
     `$work/claude-settings.json` (jq) with
     `hooks.UserPromptSubmit` → `[{"hooks":[{"type":"command","command":"<sink> prompt <work>/turns"}]}]`,
     `hooks.Stop` → the same with `stop`, and for `claude-implement` also
     `hooks.PreToolUse` → `[{"matcher":"Bash","hooks":[{"type":"command","command":"/etc/claude-code/hooks/coder-guard"}]}]`;
     then

     ```bash
     argv=(agent-env env -u ANTHROPIC_API_KEY -u ANTHROPIC_API_KEY_FILE claude
       --model "$m" --effort "$e" --permission-mode "$mode" --settings "$work/claude-settings.json")
     ```

     with `<m>`/`<e>` from `--model`/`--effort` if given, else the prefix
     defaults for the role. Refuse to start if `/etc/claude-code/hooks/coder-guard`
     is not executable for `claude-implement`.
   - Readiness (both backends, ~640 and ~927): kind `claude` waits like
     `codex` (herdr reports agent `claude`); while waiting, if the visible
     screen contains `trust this folder` or `Is this a project you trust`
     (case-insensitive), send Enter to the pane once (TUI
     `h pane send-keys "$pane" enter`; hc: the backend's own way to send a
     key, as `interrupt_member` does), and record `trusted folder` in
     `$ctl/status`.
   - `send_prompt` / `interrupt_member`: kind `claude` takes the existing
     non-agy path (`h agent prompt` / `h agent send-keys`), and hc as today.
   - Ask loop (~1105): accept `.source == "claude"` as well.
   - `finish` (~1409): accept `claude-implement`.
   - Tests in `herdr-team-test.sh`: a fake `claude` (copy of the fake codex
     pattern) records its argv and settings file; the fake herdr reports
     agent `claude` for it and, on `agent prompt` for a claude member, runs
     the settings file's `UserPromptSubmit` then `Stop` hook commands with
     fixture stdin so the real sink writes the turn; cases: `claude-review`
     up (argv: model/effort/plan/settings, no PreToolUse in settings),
     `claude-implement` up (bypassPermissions, PreToolUse guard present),
     `--model x --effort low` overrides, an `ask` answered through the sink,
     a trust-question screen answered once, `finish` on claude-implement,
     and the hc backend for one role.
   → verify: `nix build --no-link .#nixosConfigurations.p620.config.system.build.toplevel`
   (herdr-team's and the sink's checkPhases run the tests).

4. Lead: `just test-host razer`; agy diff review; PR; merge; bus
   announcement; switch p620, then razer via p620. Live smoke on p620 in a
   scratch worktree inside herdr: `herdr-team up zz3268 claude-review`,
   `herdr-team ask zz3268 claude-review <file asking for one word>` → ok with
   a non-empty answer, `herdr-team down zz3268`; then the worktree is
   removed.
