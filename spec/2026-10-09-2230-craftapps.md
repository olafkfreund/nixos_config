# Spec: install the ArtCraft Crafting Apps on p620 and razer

## Design

**The flake, `github:olafkfreund/nix-craftapps`, in its own repo:**

- `apps.json` holds a version, tag, URL and SRI hash for each of the 12 apps,
  for x86_64 and aarch64.
- One generic builder, `package.nix`, unpacks the upstream
  `<app>-<ver>-linux-<arch>.tar.gz`. `autoPatchelfHook` patches it against
  glibc and ALSA, and `runtimeDependencies` puts the libraries the apps load
  at runtime on the RPATH: D-Bus, libGL, Vulkan, Wayland, xkbcommon and the X11
  set. It installs `bin/<app>`, `bin/<app>-cli` and the desktop file, icons,
  metainfo and MIME XML upstream ships.
- `nixosModules.default` offers `programs.craftapps`:
  - `enable`;
  - `enableAll`;
  - `apps.<name>.enable` and `apps.<name>.package`;
  - `linkFonts` (default `true`), which sets `fonts.fontDir.enable` and
    links `/usr/share/fonts` to the system font directory.
- The module takes its packages from the flake itself, so no overlay is needed.
- A daily workflow updates `apps.json`, runs `nix flake check` and opens a PR.

**In this repo:**

1. `flake.nix` gains a new input:

   ```nix
   nix-craftapps = {
     url = "github:olafkfreund/nix-craftapps";
     inputs.nixpkgs.follows = "nixpkgs";
   };
   ```

   With `follows`, the apps are patched against our own glibc and graphics
   libraries, and evaluation pays for no second nixpkgs.
2. A new file, `modules/desktop/craftapps.nix`:
   - defines `features.craftapps.enable`;
   - imports `inputs.nix-craftapps.nixosModules.default` unconditionally,
     because imports cannot depend on config;
   - sets `programs.craftapps = { enable = true; enableAll = true; }` under
     `mkIf`.

   `modules/desktop/default.nix` imports it, next to `sunshine.nix`.
3. `hosts/p620/configuration.nix` and `hosts/razer/configuration.nix` set
   `features.craftapps.enable = true;`.

All three hosts import `modules/desktop/default.nix`, through
`hosts/templates/desktop.nix` → `modules/desktop.nix`. p510 never sets the
flag, so it gets only the options and evaluates the input, with no packages
and no `/usr/share` link. Its toplevel drvPath must not change.

## Alternatives rejected

- **ipeglin/artcraft-nix.** It covers 7 of the 12 apps and is controlled by a
  third party. The user chose to own the packaging.
- **ethernet8023/storytold-flake.** It builds from source and already has
  stale pins. It has no module, no update job and no licence.
- **Building from source in our flake.** effectcraft has 26 git dependencies,
  and the large workspaces would be recompiled on every daily bump. Upstream's
  binaries come in by fixed hash, so what we fetch is exactly what the hash
  pins.
- **`appimageTools.wrapType2`.** The tarballs carry the same binaries without
  the AppImage runtime. A bubblewrap FHS environment adds nothing when two
  hooks are enough.
- **Home Manager module.** It cannot create `/usr/share/fonts`, so the text
  tools would find no fonts.
- **`environment.systemPackages` from the overlay in a host file.** The repo
  rules want a feature flag in `modules/`.

## Risks

- **Pre-1.0 apps that release daily.** A release can crash or drop an
  architecture. The flake lock pins the version, `nhs` test-builds before
  every switch, and rollback is the previous generation.
- **The runtime library set.** If upstream starts loading a new library, the
  app fails at launch while the build still passes. The flake's checks launch
  only the CLI, so the GUI check is a manual one, done at this deploy.
- **`/usr/share/fonts` on NixOS.** It is a tmpfiles symlink. Nothing else on
  p620 or razer uses `/usr/share`; the build checks that nothing already
  claims the path.
- **Closure size.** It grows by about 0.6 GB per host: 12 archives of
  15-75 MB, some larger once unpacked. razer's root has room, but its ESP is
  unaffected either way, because this adds no kernel or initrd change.
- **A new public input under our name.** It is maintained by us; the update
  PRs need a glance before merging.

## Verification

- In nix-craftapps, `nix flake check` passes: every app builds and the module
  evaluates. CI runs on both architectures.
- `nix build` of the p620 and razer toplevels passes. p510's toplevel drvPath
  is identical before and after.
- After deploy, on p620 and razer:
  - all 12 launcher entries are present;
  - `<app>-cli --help` works for each app;
  - three GUIs start on Hyprland: PhotoCraft, EffectCraft (ALSA) and DeckCraft;
  - `/usr/share/fonts` resolves to the system fonts, and one text tool lists
    them.
