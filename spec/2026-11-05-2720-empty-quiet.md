# Spec: an empty quiet.json doesn't silence agent summaries

## Design

One change, in `gate_quiet` (`pkgs/agent-say/agent_say.py`), at the start of its `try`, before the file is parsed:

```python
st = path.stat()
if st.st_size == 0 and time.time() - st.st_mtime > QUIET_SETTLE:
    return None  # an old empty file isn't a request for quiet; a new one may be mid-rewrite
```

`QUIET_SETTLE = 5` seconds, a module constant. `stat()` raises `OSError` for a missing or unreadable file, which
the existing `except` already turns into quiet. A newly empty file, and everything else, carries on to the
existing `json.loads`, which fails on zero bytes, so it stays quiet. A modification time in the future gives a negative
age, which also stays quiet.

`docs/applications/agent-voice.md`, the "Snooze and quiet state" bullet, gets one sentence on this exception.

`gate_quiet` runs before each sentence and from `agent-say held`, so `speaker = "nixi"` and the old voice both get
this with no further change.

## Alternatives rejected

- **Any empty file counts as clear:** a truncate-and-rewrite could let him speak during a call. It isn't
  known how Omarchy writes this file, so the rule has to be safe for that.
- **Writing `{"dnd":false}` to razer's file once:** no code, but the trap stays for anyone else. The user
  chose the code.
- **Treating a missing file as clear:** approved to stay as it is.
- **Stripping whitespace:** whitespace is invalid content, and nothing has shown it.
- **A config option for the 5 seconds:** nothing needs to change it.

## Risks

- **A rewrite that holds the file empty for more than 5 seconds** would read as not quiet. That's unlikely for
  a file this
  small. The change only opens this one gate, and Do Not Disturb has its own gate (`gate_dnd`).
- **Razer starts speaking** once deployed, since it has been silent since at least Oct 22. That's the intent.
  Its summaries use the `claude` backend, so turn text starts going to `claude -p` on that host: already
  configured, but held back by this gate until now.

## Verification

**Tests in `pkgs/agent-say/test_agent_say.py`,** run by the package build, with file ages set by `os.utime`:

- zero bytes, modified 60 s ago: clear;
- zero bytes, just written: quiet;
- zero bytes, modified in the future: quiet;
- whitespace only, modified 60 s ago: quiet;
- the existing cases unchanged, including a missing file being quiet.

```bash
nix build .#nixosConfigurations.razer.config.features.agentVoice.package --no-link
```

Each of the first two fails with the two new lines removed.

**Live on razer, after deploy:**

- `agent-say held` exits 0 while Do Not Disturb is off;
- a real turn over 60 s on razer is spoken;
- with Do Not Disturb on, `agent-say held` exits 1.
