# Spec: Restore Exposé and remove AI Kit

## Decisions from the owner

Given 2026-11-05, with the instruction that nothing already in use may break:

- Exposé: restore on p620 and razer, with the hot corner off.
- AI Kit: remove. `~/.local/share/aikit` stays.

## Design

### Exposé

Declare the plugin in the Altscape shape, so it cannot vanish again.

- **`pkgs/expose-plugin/default.nix`**, registered in `pkgs/default.nix` beside `altscape`.
  Fetches `kristofferR/omarchy-expose` at `f283002259f5aba75da17b3f5dd4081bddc257f5` (v5.0.0
  plus fixes, 2026-10-26), hash `sha256-kzs/qxLtQ9AI+6eK4aSY/WrD7br1Rf+Qs8mTKfOxjsQ=`.
  - `postPatch` changes `Overview.qml:134` from
    `root.pluginEntry.hotCornerEnabled !== false` to `=== true`, with `--replace-fail`. The
    corner is then off unless turned on in Exposé's settings, and that toggle
    (`Overview.qml:685`) still works. A package default avoids writing to `shell.json`, which
    `omarchy-enable-once.nix` deliberately never does.
    Neither host has a saved `hotCornerEnabled` in `shell.json` today (checked 2026-11-05).
    The plan rechecks this before the first login, because a saved `true` would win.
  - `activate-window` and `background-blur-session` are run directly by `Overview.qml`. Their
    `#!/bin/bash` line is rewritten to a store bash, and a line after it prepends a store
    `PATH` holding `hyprland`, `jq`, `util-linux` (`flock`) and `coreutils` (`timeout`,
    `sleep`, `mkdir`, `kill`). Prepending keeps their `command -v` guards working. `hyprland`
    comes from `config.programs.hyprland.package`, like Altscape.
  - `installPhase` uses Altscape's `cp --no-preserve=mode`, which drops the executable bit, so
    it runs `chmod +x` on both helpers, and a build-time check fails if either is not
    executable.
- **`hosts/common/nixos/omarchy-expose.nix`**: sets
  `programs.nixarchy.plugins."expose.window-overview".src` and adds the id to
  `local.omarchy.enableOnce`. Imported from `hosts/{p620,razer}/nixos/nixarchy.nix`.
- **The key does not move.** `SUPER + E` stays in `shared` in `omarchy-keys.nix`, with its
  table row and the razer sentence at `desktop.md:164`, all of which become true. No fragment
  and no `bindings.lua` edit. The copy at line 116 of p620's `bindings.lua` is harmless,
  because `repo-keys.lua` unbinds that chord first, so it stays.
- **Optional features stay off.** `workspace-gesture.lua` loads only if a user requires it,
  and nothing here does. No other plugin in `shell.json` sets a hot corner.

### AI Kit

- Delete the `SUPER + CTRL + J` entry from `omarchy-keys.nix` and its row at `desktop.md:133`.
- Delete the bind and its two comment lines from `~/.config/hypr/bindings.lua` on p620 and
  razer. Without this, the copy comes back to life when the declaration goes. The edit is
  exact-match only, stops if the text differs, and leaves a dated backup beside the file.
  `local.omarchy.keys.unbind` is rejected below.
- On p620 only, delete these dangling symlinks, after confirming each one is dangling:
  - `~/.local/bin/aikit`, `aikit-selftest`, `aikit-status` and `aikit-sync`
  - `~/.config/systemd/user/aikit-sync.service` and `aikit-sync.timer`
  - the `aikit-sync.timer` link in `timers.target.wants`
- Move `~/.config/systemd/user/aikit-sync.service.d`, which holds `nixos-path.conf`, to
  `~/.local/state/nixarchy-local/aikit-sync.service.d.removed`, stopping if that path exists.
  Then run `systemctl --user daemon-reload`.
- `~/.local/share/aikit` is not touched.
- Immediately before this cleanup, recheck on each host that the unit is not active, that each
  link target is still missing, and that the `bindings.lua` text is still exactly as expected.
  If anything differs, stop and report it.

## Alternatives rejected

- **`omarchy plugin add`, as upstream documents:** undeclared, which is how this broke.
- **Turning the corner off with `omarchy-shell expose hotCorner off` from a hook:** writes to
  `shell.json`, needs the shell running, and leaves the corner live until the hook has run.
- **Adding `SUPER + CTRL + J` to `unbind`:** leaves the chord named in the module and in
  "Unbound on both hosts" in the docs, which the approved outcome rules out.
- **Leaving the AI Kit leftovers:** a dangling `timers.target.wants` link would remain a false
  lead in every future diagnosis. Their targets are already gone, so nothing is lost.
- **p620 only for Exposé:** owner chose both hosts.

## Risks

| Risk | Host | Handling |
| --- | --- | --- |
| A plugin import failure kills the whole Omarchy shell, as an unavailable QtMultimedia import does in this repo's history | both | All non-test QML at this rev imports only `QtQuick`, `QtQuick.Layouts`, `QtQuick.Effects`, `Quickshell`, `Quickshell.Io`, `Quickshell.Hyprland`, `Quickshell.Wayland`, and `qs.*`. A build cannot prove the live shell loads it, so the first load on p620 is an explicit gate: razer waits until the shell has started with the plugin loaded. |
| Enable-once fires only at post-boot, so a bad plugin shows up at next login, not during the switch | both | Disable in Setup > Plugins, or roll back. Enable-once leaves its per-host marker, so turning it off sticks. |
| Exposé raises Hyprland blur while open and restores it on close. A crash mid-overview could leave it raised | both | Upstream's behaviour, and it reverts on `hyprctl reload` or next login. Check open and close restore the same value. |
| Live previews rely on screencopy, which may behave differently on razer's hybrid NVIDIA GPU | razer | Upstream documents fallback labels. Razer is checked separately. |
| A running session keeps old binds, and a reload can lose layouts in old sessions | both | No forced reload. Keys change at next login or at a reload the owner chooses. |
| Someone uses `SUPER + CTRL + J` for something else | both | Nothing else binds it. The chord only becomes free. |
| Deleting a link that is not actually dangling | p620 | Each deletion is guarded by a `[ -L ] && [ ! -e ]` test. |
| The `pcall(require, "hypr.flea-binds")` line or other work in `bindings.lua` is disturbed | both | The edit removes three exact lines only, and the diff against the backup is checked to be just those lines. |

Altscape, Flea, Omarchy's shell and every other declared key are not edited. #2694 changes
`hosts/{p620,razer}/nixos/nixarchy.nix` too, so whichever merges second rebases one import line.
