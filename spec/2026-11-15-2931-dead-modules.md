# Spec: delete dead modules and fix the module templates

## Design

1. **Deletion by proof.** Delete the candidate list in the intent in one commit, then run
   `scripts/config-snapshot.sh` (from #2929). Evaluation succeeding and all three hosts `IDENTICAL` proves nothing
   imported them (an import of a deleted path is an evaluation error). A file that turns out to be used is restored
   and left out of this task. Also drop references to deleted files in docs and comments.
2. **specialArgs.** Remove `sharedVariables` and `hardwareProfiles` from `flake.nix`'s `specialArgs` (no reader in
   `hosts/`, `modules/`, `home/`, `Users/`). Same proof.
3. **Structure check.** Remove the `modules/*/` wrapper rule from `checks/default.nix:90-100` (explicit leaf imports
   are the house rule, AGENTS.md "Explicit imports only"); keep the rest of that check.
4. **Templates.** `modules/TEMPLATE.nix`: `options.features.<name>` with `mkEnableOption` and
   `config = mkIf cfg.enable { ... }` (AGENTS.md "Module shape"). `modules/SYSTEMD_SERVICE_TEMPLATE.nix`:
   `DynamicUser = true`, `ProtectSystem = "strict"`, `ProtectHome = true`, `NoNewPrivileges = true`, no static user;
   `StateDirectory` for state.

## Alternatives rejected

- Grep-only deletion: imports built by string interpolation (e.g. `flake.nix:472`) evade grep; evaluation does not.
- Move the templates to a new `templates/` folder: churn in docs for no behaviour gain.

## Risks

- A deleted file used only by p510 evaluation: covered, p510 is evaluated, and its configuration is built on p620
  (owner OK for this roadmap, 2026-11-15); nothing is built on or copied to p510.
- A file read by a script or doc rather than Nix (e.g. `docs_gen`): grep `docs_gen/ scripts/ docs/ Justfile` for each
  deleted path before deleting.

## Verification

`scripts/config-snapshot.sh` (from #2929) diff against a baseline snapshot of the same `main` commit (same
`flake.lock`), both evaluated with `system.configurationRevision` pinned: each host's toplevel `.drv` identical.
Keep `shared-variables.nix`, `amd-gpu.nix`, `nvidia-gpu.nix` (host `variables.nix` import them directly). `nix flake check --no-build` evaluates the checks, and
`nix build .#checks.x86_64-linux.<structure check>` passes. `just check-syntax`. CI green.
