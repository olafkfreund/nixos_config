# Spec: fleet constants, allowBroken and honest aggregator names

## Design

1. **`hosts/common/fleet.nix`** (new, plain data, imported with `import`):
   `{ p620.tailnet = "100.69.100.115"; p510 = { tailnet = "100.118.96.32"; lan = "192.168.1.65"; };
   razer.tailnet = "100.90.72.124"; }`. `192.168.1.65` is p510 (the NFS media server and Sunshine host), not p620.
   Every non-comment use of these four addresses under `hosts/` uses it (string interpolation, or
   `"${fleet.p620.tailnet}"` as a `networking.hosts` attribute name). Comments and docs keep the literal;
   `modules/desktop/sunshine.nix:114` is an option `example` and stays.
2. **allowBroken**: delete `allowBroken = true;` from the three hosts (Codex evaluated all three with it false:
   identical `.drv`). `modules/services/citrix-workspace.nix:33` stays (host-wide only when citrix is enabled; off on
   every host).
3. **Dead overlay**: `modules/overlays/default.nix` overrides top-level `pkgs.openrazer-daemon`, which nothing reads
   (consumers use `python3Packages.openrazer-daemon`). Delete the file and its import in `modules/core.nix`, kept
   only if all three `.drv` stay identical.
4. The `modules/development/default.nix` import stays per host: #2932 showed that moving it changes all three `.drv`.

## Alternatives rejected

- A `fleet` NixOS option: data that only feeds string literals does not need the module system.
- Renaming aggregator files: churn in imports and docs; fixing what they import is enough.

## Risks

- `allowBroken` removal can fail evaluation: per host, restore with a comment.
- Overlay move can reorder `nixpkgs.overlays`: verified by the `.drv`; reverted if it changes.

## Verification

`scripts/config-snapshot.sh` against the `main` baseline: p620, razer, p510 `IDENTICAL`; `git grep` shows the two
addresses only in `hosts/common/fleet.nix` and comments.
