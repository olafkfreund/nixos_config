# Spec: graphify knowledge graph for Claude Code, Codex and Antigravity

## Design

- **Package**: `pkgs.customPkgs.graphify` in `pkgs/default.nix` is nixpkgs
  `graphify` (0.9.91) with the `mcp` and `pdf` optional dependencies added via
  `overridePythonAttrs`. It ships `bin/graphify` and `bin/graphify-mcp`
  (`graphify.serve:_main`). It's a leaf package, so it doesn't invalidate the
  binary cache for anything else.
- **Flag**: `features.development.graphify` (`Users/common/features.nix`), set
  true in `Users/olafkfreund/profile.nix`. p620 and razer import that file and
  p510 doesn't. Each module below reads the flag directly (#2934).
- **CLI + env + gitignore**: new `home/development/graphify.nix`, imported from
  `home/development/default.nix`. It adds the package,
  `GRAPHIFY_BACKEND=none`, and `programs.git.ignores = [ "graphify-out/" ]`.
- **Skills**: `home/development/claude-code-skills/default.nix` builds two
  trees from the package: `graphify/skill.md` + `skills/claude/references` →
  `~/.claude/skills/graphify`, and `skill-agents.md` +
  `skills/agents/references` → `~/.agents/skills/graphify` (Codex and agy).
  These are the files `graphify install` would copy, so they always match the
  installed version.
- **MCP**: one stdio server, `graphify-mcp` with no arguments. It starts
  without a graph and every tool takes `project_path`, so one global entry
  serves every repo.
  - Claude: added to `sharedMcpDesired` in `claude-code-mcp.nix`, with a store
    path that the activation reconcile keeps current.
  - agy: added to `sharedMcpServers` in `antigravity-config.nix`.
  - Codex: an idempotent `codex mcp add graphify -- <profile>/bin/graphify-mcp`
    activation in `graphify.nix`, the same pattern as `codexNixdMcp`.
- **Codex `multi_agent`**: no change. `codex features list` shows it is
  already effectively on.

## Alternatives rejected

- `uv tool install graphifyy` + `graphify install`: imperative, unpinned, and
  writes into the synced `~/.claude`.
- The `leiden` extra: graspologic pulls `future`, which is broken on
  Python 3.14. graphify falls back to Louvain.
- Tracking upstream 0.9.112 with a source override: nixpkgs is 21 releases
  behind but working. A forced hash needs a version guard. Revisit if a needed
  fix lands upstream.
- Always-on hooks (`graphify claude install`, `--strict`): see the intent's
  constraints.

## Risks

- Claude MCP reconcile only adds and replaces. Turning the flag off later
  needs `graphify` added to `retiredMcpServers`. Documented in the module.
- The query log at `~/.cache/graphify-queries.log` stays on (local only).
- Prompt injection during the semantic pass over docs. The code-only default
  limits it.
